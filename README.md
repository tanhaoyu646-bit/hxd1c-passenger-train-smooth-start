# 旅客列车平稳起动虚拟实训

本项目是一个独立的 H5 教学实训项目，用于训练旅客列车由停车状态平稳起动的基本操纵逻辑。它从“确认行车凭证”项目复制技术基座后独立开发，不与原项目共享 Git 仓库，也不会修改原项目文件。

## 教学边界

- 当前使用 HXD1C 驾驶台、株洲站1道和七斗冲方向教学线路。
- 客车采用参考既有游戏车辆外观的程序化教学模型，用于表现12辆编组和后部瞭望。
- 动力模型按 HXD1C 138 t、12辆客车和850 t列车总质量进行课堂标定；加速度、冲动阈值用于教学评价，不作为车辆型式试验或规章限值。
- 完整发车作业包含正常、天气恶劣、绿色许可证和路票四类场景；平稳起动专项仅设置平道与4‰教学等效上坡道。

## 已实现

- 20 项完整发车与平稳起动作业流程，总分 100 分：包含设备初始位置、LKJ 参数、升弓合主断、简略制动机试验、列车缓解、列尾风压、两次车机联控、地面与机车信号确认、发车手信号、停放制动缓解和平稳起动。
- 教学模式顺序提示；考评模式一般错误扣分但不中断，安全红线强制停车。
- 列车管缓解传播、牵引建立、车钩力传递、全列起动比例、加速度和冲动的连续计算。
- 平稳起动六阶段教学：1～2 级低级位加载、保持低级位、确认 12 辆全列依次起动、后部瞭望、逐级加牵引、接近出站信号机按压 LKJ“开车／7”。
- 直接点击三维出站信号机、机车信号、风压表、LKJ 和驾驶台手柄；CIR和列尾功能沿用“确认行车凭证”项目的设备模拟器。
- LKJ2000 以用户提供的原程序截图作为整机视觉底层，保持原屏幕、边框和实体键比例；透明热区负责“设定、查询、确认、方向键”等交互，包含16项参数、揭示查询、开车对标以及绿色许可证／路票非正常行车确认。
- 右侧原边电流、列车管压力、制动缸压力和工况默认隐藏，只能由“查询→工况显示／设备状态”调出，关闭并重新进入 LKJ 后恢复隐藏。
- LKJ首次打开为无弹窗的未设定监控主界面；按“设定”后显示与用户参考图同坐标比例的完整三栏参数窗口（约617×323／800×615），窗口尺寸不随内容伸缩。
- 绿色许可证解锁限速60 km/h、红色控制线65 km/h，出站前机车信号红黄、越过出站信号机后转绿；路票解锁限速45 km/h、红色控制线50 km/h，机车信号保持红绿显示。
- 地面信号与机车信号显示差异本身不再触发系统自动切牵引或投入制动；核对错误仍记录扣分并提示学生主动减速或停车，既有红灯防护逻辑保留。
- 正面、左侧窗、右侧窗、左后部瞭望、右后部瞭望五个独立视角；左右窗保留原驾驶室画面，左右后部瞭望为不带驾驶室窗框的纯Three.js镜像视角。
- 全列起动时，机车视点和12辆客车按车钩力传播顺序产生幅度很小、快速衰减的纵向顿动及车体横摇；不使用持续随机抖动。
- 完整发车作业和平稳起动专项使用两个独立地址：根目录为完整作业，`/smooth-start/` 为专项；专项不显示天气、绿证和路票选项。
- 平道以1级建立牵引、必要时使用2级；上坡道由单阀保持机车制动，以2级建立牵引后再逐步缓解单阀，过早解除保持会记录后溜风险。
- 专项采用独立9项流程和评分；完整发车作业仍保持原20项流程及四类行车场景。
- 手机端提供横屏进入、方向提示、安全区避让、可视视口高度、44 px 场景按钮、侧拉流程面板和专项底部动态状态条。

## 本地运行

```powershell
python -m http.server 4175
```

然后分别打开：

- 完整发车作业：`http://127.0.0.1:4175/`
- 平稳起动专项：`http://127.0.0.1:4175/smooth-start/`

三维资源通过 `fetch` 加载，不能直接双击 `index.html` 运行。

## 校验

```powershell
npm run check
```
