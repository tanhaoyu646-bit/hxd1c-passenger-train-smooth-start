# 旅客列车平稳起动虚拟实训

本项目是一个独立的 H5 教学实训项目，用于训练旅客列车由停车状态平稳起动的基本操纵逻辑。它从“确认行车凭证”项目复制技术基座后独立开发，不与原项目共享 Git 仓库，也不会修改原项目文件。

## 教学边界

- 当前使用 HXD1C 驾驶台、株洲站1道和七斗冲方向教学线路。
- 客车采用参考既有游戏车辆外观的程序化教学模型，用于表现12辆编组和后部瞭望。
- 动力模型按 HXD1C 138 t、12辆客车和850 t列车总质量进行课堂标定；加速度、冲动阈值用于教学评价，不作为车辆型式试验或规章限值。
- 第一版场景为正常、平直、干燥黏着条件。

## 已实现

- 19 项完整发车与平稳起动作业流程，总分 100 分：包含设备初始位置、LKJ 参数、升弓合主断、简略制动机试验、列车缓解、列尾风压、行车凭证／发车通知、信号确认、停放制动缓解和平稳起动。
- 教学模式顺序提示；考评模式一般错误扣分但不中断，安全红线强制停车。
- 列车管缓解传播、牵引建立、车钩力传递、全列起动比例、加速度和冲动的连续计算。
- 平稳起动六阶段教学：1～2 级低级位加载、保持低级位、确认 12 辆全列依次起动、后部瞭望、逐级加牵引、接近出站信号机按压 LKJ“开车／7”。
- 直接点击三维出站信号机、机车信号、风压表、LKJ 和驾驶台手柄；CIR和列尾功能沿用“确认行车凭证”项目的设备模拟器。
- LKJ2000 区分“设定、查询、确认、方向键”，包含16项参数、查询选择、揭示查询、开车对标以及绿色许可证／路票非正常行车确认。
- 正面、左侧窗、右侧窗、左后部瞭望、右后部瞭望五个独立视角；左右窗保留原驾驶室画面，后部瞭望显示12辆车列由前向后依次起动。
- 完整发车作业和平稳起动专项两个入口，共用同一动力、设备和评分状态。
- 桌面端双面板和手机端独立侧拉栏。

## 本地运行

```powershell
python -m http.server 4175
```

然后打开 `http://127.0.0.1:4175/`。三维资源通过 `fetch` 加载，不能直接双击 `index.html` 运行。

## 校验

```powershell
npm run check
```
